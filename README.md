# VitaeFluxum para ChatGPT y Codex

Este complemento instala la habilidad **VitaeFluxum**, creada para trabajar con:

- personajes realistas y consistentes;
- blueprints de rostro, cuerpo y vestuario;
- continuidad de identidad, ropa y lateralidad;
- escenarios cinematográficos;
- storyboards 3×3;
- reconstrucción de un fotograma concreto;
- prompts de vídeo con timeline.

## Instalación desde GitHub

1. Abre ChatGPT/Codex y entra en **Configuración**.
2. Ve a **Complementos**.
3. Pulsa **Añadir → Añadir un marketplace**.
4. Pega la dirección de este repositorio de GitHub.
5. Deja vacío el campo **Path** y pulsa **Importar marketplace**.
6. Busca **VitaeFluxum** e instala el complemento.
7. Abre un chat nuevo para empezar a utilizarlo.

La disponibilidad de los complementos y habilidades puede depender del plan, la cuenta y la versión de la aplicación.

## Cómo utilizarlo

Puedes invocarlo escribiendo `$vitaefluxum` y explicando qué necesitas. Por ejemplo:

> $vitaefluxum Crea un blueprint completo de este personaje y conserva exactamente su identidad y su ropa.

También puede activarse automáticamente cuando solicites un blueprint, un storyboard o un prompt de vídeo que necesite continuidad visual.

## Privacidad

Este complemento solo contiene instrucciones y plantillas. No incluye servidores MCP, no conecta cuentas externas y no envía archivos a servicios adicionales.
